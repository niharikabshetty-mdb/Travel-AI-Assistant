# 2.11 Google ADK

## 1. Introduction

Google Agent Development Kit (ADK) is a framework for developing AI agents and agent-based applications.

It provides tools for creating agents that can reason about tasks, use tools, interact with other agents, and perform multi-step workflows.

---

## 2. Why Google ADK is Useful

Google ADK can be used to build AI systems that are more capable than a simple question-and-answer application.

It can support:

- AI agents
- Tool usage
- Multi-step tasks
- Agent workflows
- Multi-agent systems
- Integration with AI models

---

## 3. Google ADK and AI Agents

An AI agent can receive a goal and decide what actions are required to complete it.

A simplified workflow is:

```text
User Request
     ↓
AI Agent
     ↓
Reasoning / Decision
     ↓
Tool or Action
     ↓
Result
     ↓
Final Response

For example, an advanced travel agent could decide to search travel information, compare options, and then create an itinerary.

4. Google ADK in the Travel AI Assistant

Google ADK could be used in a future version of the Travel AI Assistant to create an intelligent travel-planning agent.

The agent could potentially:

Understand travel requirements
Use external tools
Retrieve travel information
Perform multiple planning steps
Generate a final itinerary
5. Google ADK in the Current Project

Google ADK is not currently implemented in the Travel AI Assistant MVP.

The current application uses a direct OpenAI API integration through the FastAPI backend.

The current system is therefore an AI-powered travel planning application, but it does not yet use an agent framework.

6. Future Use

Google ADK could be introduced later if the project is extended into a more autonomous travel agent.

For example, separate agents could handle:

Travel Planning Agent
        ↓
Destination Information
        ↓
Activity Planning
        ↓
Food Recommendations
        ↓
Final Itinerary

7. Conclusion

Google ADK provides tools for developing AI agents and complex agent-based workflows.

Although it is not used in the current MVP, it can be considered for future versions that require more autonomous and multi-step travel planning.
