# 2.9 Google Cloud Platform (GCP)

## 1. Introduction

Google Cloud Platform (GCP) is a cloud computing platform provided by Google.

It provides services for hosting applications, storing data, running APIs, managing databases, and deploying AI applications.

---

## 2. Why GCP is Useful

A travel assistant application can be deployed to the cloud so that users can access it through the internet.

GCP can provide infrastructure for:

- Hosting web applications
- Running backend services
- Managing APIs
- Storing application data
- Monitoring applications
- Scaling applications

---

4. GCP and AI Applications

GCP provides several services that can support modern AI applications.

For example, cloud infrastructure can be used to:

Host AI-powered applications
Run backend APIs
Store application data
Monitor application performance
Scale applications based on demand
5. Environment Variables and Cloud Deployment

When deploying the Travel AI Assistant to the cloud, sensitive configuration values should be stored securely.

Examples include:

OpenAI API key
MongoDB connection string
Firebase credentials

These values should not be hardcoded into the source code.

6. GCP in the Current Project

GCP is not currently implemented in the Travel AI Assistant MVP.

The application currently runs locally using:

Next.js
Node.js
FastAPI
MongoDB Atlas
OpenAI API
Firebase Authentication

GCP was studied as part of the curriculum as a possible cloud deployment platform.

7. Future Use

GCP can be used in the future to deploy the Travel AI Assistant online.

Cloud deployment would allow users to access the application without running the frontend, Node.js gateway, and FastAPI backend locally.

8. Conclusion

Google Cloud Platform provides cloud infrastructure and services for developing, deploying, and scaling applications.
