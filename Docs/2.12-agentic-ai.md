# 2.12 Agentic AI / Agent Skills

## 1. Introduction

Agentic AI refers to AI systems that can understand a goal, make decisions, use tools, and perform multiple steps to complete a task.

Unlike a simple chatbot that mainly generates a response, an AI agent can take actions based on the task given by the user.

---

## 2. Basic Agent Workflow

A simplified agent workflow is:

```text
User Goal
   ↓
AI Agent
   ↓
Reasoning / Planning
   ↓
Tool Usage
   ↓
Result
   ↓
Final Response

Agent Skills

Agent skills are capabilities that allow an AI agent to perform specific tasks.

For a travel assistant, possible skills could include:

Destination research
Itinerary planning
Activity recommendations
Food recommendations
Travel information retrieval
Budget planning
4. Agentic AI for Travel Planning

An advanced Travel AI Assistant could use multiple skills to complete a travel request.

For example:

User: Plan my trip to a destination

        ↓

Travel Planning Agent

        ↓

Destination Research
        ↓
Activity Planning
        ↓
Food Recommendations
        ↓
Itinerary Generation

This would make the system more autonomous.

5. Agentic AI in the Current Project

Agentic AI is not currently implemented in the Travel AI Assistant MVP.

The current application uses OpenAI directly through the FastAPI backend to generate structured travel itineraries.

The system therefore provides AI-powered travel planning but does not yet perform autonomous multi-step actions.

6. Future Enhancement

Agentic AI could be added in a future version.

Possible improvements include:

Using external travel APIs
Searching for current travel information
Comparing travel options
Using multiple specialized agents
Automatically performing planning steps
Combining tools with AI reasoning

7. Conclusion

Agentic AI enables AI systems to work toward goals using reasoning, tools, and multiple steps.

It is a possible future enhancement for the Travel AI Assistant, while the current MVP focuses on providing reliable AI-generated travel itineraries through a simpler architecture.
